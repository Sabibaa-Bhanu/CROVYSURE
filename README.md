# CROVYSURE
Crop Intelligence &amp; Risk Platform

A professional agricultural surveillance and crop intelligence platform designed for farmers, field officers, and district agricultural departments under PMFBY.

## Key Features
- **Crop Health Overview**: Real-time district surveillance across registered plots and sequential farmer observations.
- **Risk Forecast**: 7-day predictive risk modeling across disease, pest pressure, and microclimatic humidity factors.
- **Follow-up Monitoring**: Sequential weekly canopy photograph tracking with comparative severity deltas and actionable follow-up recommendations.
- **Expert Validation & Damage Alerts**: Officer verification workflows and threshold-based pest advisories.
- **Regional Surveillance Matrix**: Zone-level monitoring across Nashik, Pune, Nagpur, and Chhatrapati Sambhajinagar.

## Tech Stack
- **Framework**: React 19 + Vite 7
- **Routing**: React Router v7
- **Styling**: Tailwind CSS v4
- **Icons & Visuals**: Lucide React + Recharts + Leaflet
